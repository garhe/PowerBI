# PowerBI

This repository contains Power BI assets and metric documentation for weekly and monthly CCID retention reporting.

## Contents

- `retention-metric-definitions.md`: business-facing definitions for weekly and monthly CCID and retention metrics

## Optional Local Asset

- `Speech CU.pbix`: Power BI Desktop report file (local file, not currently committed in this repository)

## Notes

- Weekly metrics use a 7-day calendar week.
- Monthly metrics use a calendar month.
- Retention is based on returning CCIDs across periods, not just total count.
